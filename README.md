# OCCCI Member Connect

Responsive member PWA and branch admin CMS prototype for 52 OCCCI branches across six districts.

Deploy on Vercel using framework Other and output directory dist. No install or build step is required. Import into the occciproject-archieomega team.

This is a front-end demo with session-only sample data. Verified login, backend branch permissions, Supabase, payments and native packaging are future phases.

Poppins fonts and logo assets are bundled. Serve dist with a static server for local development.
